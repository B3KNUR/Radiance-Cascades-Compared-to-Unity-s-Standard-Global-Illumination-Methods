# Radiance Cascades vs Unity Global Illumination

This repository has the experiment files for our DiGRA conference paper:
**"Comparative Evaluation of Real-Time Global Illumination Methods in Unity URP"**.

We compare Radiance Cascades with Unity's standard lighting methods
to see which one is faster and looks better.

## What's Inside
- `Measured Data/` – FPS and frame time results, and charts from the paper
- Video comparison: [YouTube playlist](https://www.youtube.com/watch?v=daDjPJyB86o&list=PLaHv1eGKS6CyZF2IG05RV7KAHvvU5-xIQ)
